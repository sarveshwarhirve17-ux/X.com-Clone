# 🐦 X (Twitter) Clone

A simple practice project where I tried to recreate the home page of X (Twitter) using **HTML** and **Tailwind CSS**.

It only has the front-end design for now. There is no JavaScript or backend yet.

## ✨ What's in it

- Left sidebar with X logo, menu items (Home, Explore, Notifications, etc.), Post button and profile card
- Middle feed with "For you" and "Following" tabs
- Box to write a post, with icons for image, GIF, poll, emoji, schedule and location
- A few sample posts with reply, repost, like and views icons
- Hover effects on menu items and post icons
- Search bar on the right side
- On small screens the sidebar shows only icons, and the right side is hidden

## 🛠️ Built with

- HTML
- Tailwind CSS
- Google Material Symbols (for icons)
